# Birthday Website

Buka `index.html` (atau jalankan dengan Live Server di VS Code). Perlu internet karena library dimuat dari CDN.

## Struktur
- `index.html` : kerangka halaman dan urutan script
- `css/style.css` : gaya global dan animasi
- `js/config.js` : **edit di sini**: nama, tanggal, foto, alasan, surat
- `js/setup.js` : alias React, Framer Motion, Lucide
- `js/music.js` : musik latar
- `js/utils.js` : helper dan efek (hati melayang, confetti)
- `js/components/` : Welcome, Hero, Memories, Reasons, Letter, Surprise
- `js/App.js` : navigasi, pemutar musik, render utama

Urutan script di `index.html` tidak boleh ditukar.
